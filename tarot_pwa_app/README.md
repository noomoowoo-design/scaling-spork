# タロット記録 PWA版

## 使い方

- `index.html` をブラウザで開くと記録アプリとして使えます。
- PWAとしてホーム画面に追加するには、GitHub Pages / Netlify / Vercel などの HTTPS 環境にこのフォルダを配置してください。
- ローカルファイルとして直接開いた場合、記録やバックアップは使えますが、Service Worker とインストール機能は動かない場合があります。

## 追加済み機能

- 記録の再編集
- 後日の振り返り追記
- JSONバックアップ
- JSON復元
- CSV出力
- Web App Manifest
- Service Workerによるオフラインキャッシュ
- PWAアイコン
